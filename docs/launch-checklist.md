## 決済

- [ ] 👤 本番の決済アカウントの審査が通っている

- [ ] 本番とテストのキー・価格 ID が混ざっていない
- [ ] 領収書・請求メールが届く
- [ ] 👤 少額の本番決済を自分で試し、返金までできた

## セキュリティ・データ

- [ ] 秘密情報がリポジトリに含まれていない（履歴も含めて確認）

- [ ] 認証・認可：他のユーザーのデータを見られない
