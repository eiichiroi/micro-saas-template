# 意思決定ログ

プロジェクト全体に関わる判断（ターゲット、価格、技術選定、ピボットなど）の記録。
機能単位の決定は各設計書の「決定事項」に書き、ここには事業・方針レベルのものを書く。

<!-- 上書きしない。変更時は取り消し線を引き、変更日・新しい内容・理由を追記する。新しい判断は末尾に追加する -->

## 書き方

- ID は `DL1`, `DL2`, … と連番にする
- 「なぜ」と「採用しなかった案」を必ず書く。後から見て判断を再検討できるようにする
- 関連するヒアリングや設計書があればリンクする

## 決定事項

### DL1：〔決定内容〕

- 日付：YYYY-MM-DD
- 状態：〔決定／取り消し〕
- 背景：〔何を決める必要があったか〕
- 理由：〔なぜそう決めたか。根拠となるヒアリングや数字〕
- 採用しなかった案：〔案と、採用しなかった理由〕
- 見直す条件：〔どうなったらこの判断を再検討するか〕
- 関連：〔docs/validation.md の #3、docs/design/01-xxx.md など〕

### DL2：〔決定内容〕

（DL1 と同じ形式でコピーして追加する）
